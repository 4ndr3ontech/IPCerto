O que é o seu Endereço IP?

O endereço IP (Protocolo de Internet) é um identificador numérico exclusivo atribuído a cada dispositivo conectado a uma rede de computadores. O IPCerto detecta instantaneamente o seu IPv4 e IPv6 públicos, além de fornecer o seu provedor de acesso (ISP), ASN e localização geográfica estimada no mapa.

Sobre o DNS Lookup

O DNS Lookup (Domain Name System) é uma ferramenta essencial para administradores de sistemas e desenvolvedores. Permite consultar os registros associados a um domínio na internet, como endereços IPv4 (registro A), servidores de correio eletrônico (registro MX) ou políticas de segurança, ajudando a diagnosticar falhas de propagação e configuração.

Como funciona o Teste de Latência?

O teste mede o tempo de resposta (RTT em milissegundos) entre o seu dispositivo e os principais resolvedores DNS globais (Cloudflare, Google e Quad9). Valores baixos indicam rotas diretas e menor atraso na navegação, sendo cruciais para jogos online e chamadas em tempo real.

Entenda a Notação CIDR

A notação CIDR (Classless Inter-Domain Routing) define blocos de endereços IP e as respectivas máscaras de sub-rede. Esta calculadora auxilia engenheiros de rede a determinar instantaneamente o endereço de broadcast, os limites de hosts úteis e a distribuição de IPs numa infraestrutura.

O que é um Vazamento WebRTC?

O WebRTC permite comunicações de áudio e vídeo diretas no navegador, mas pode expor o seu endereço IP real mesmo quando você está utilizando uma rede privada virtual (VPN) ou proxy. Esta auditoria testa se o seu navegador está vazando dados sensíveis de rede.

Para que serve o Base64?

O Base64 é um método de codificação utilizado para converter dados binários em texto ASCII legível, facilitando o transporte de informações através de redes e protocolos que lidam mal com caracteres binários. O Port Scanner verifica o estado das portas essenciais (como HTTP 80, HTTPS 443, SSH 22 e DNS 53) num host de destino. É uma ferramenta fundamental para detectar serviços ativos, analisar regras de firewall e validar a segurança de servidores.

O que é o Timestamp Unix?

O Timestamp Unix representa o número de segundos transcorridos desde 1 de janeiro de 1970 (Era Unix), desconsiderando segundos intercalares. É amplamente utilizado em bancos de dados, logs de sistemas e APIs para registrar eventos de forma universal e independente de fusos horários.

Análise de JSON Web Tokens (JWT)

O JWT é um padrão aberto baseado em JSON para criar tokens de acesso seguros entre aplicações. Este decodificador permite inspecionar o cabeçalho (algoritmo e tipo) e o corpo (payload com claims e dados do usuário) instantaneamente no seu navegador, sem expor chaves secretas ou credenciais.
